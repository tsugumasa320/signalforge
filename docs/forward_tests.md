## 日次処理

`uv run python scripts/run_forward_tests.py --init` は未登録口座のみ初期化します。既存口座をリセットしません。

`uv run python scripts/run_forward_tests.py` を GitHub Actions が毎日20:17 JST予定で実行します。

1. Yahooの日足2年分を取得。過去データは指標計算に使い、登録以前の売買を作りません。
2. 保存済み注文だけを次の取引日の始値で仮想約定します。判断の記録時刻が始値の時刻より後なら約定を拒否します。
3. 終値でスクリーニングし、候補・注文・時刻・参照した約定用価格を保存します。
4. 過去の判断・約定を書き直さず、新しい取引日を追加します。同日の再実行は売買を増やしません。
5. 実行を休んだ期間は既存注文と設定済みストップだけを処理し、過去の日付に新しいスクリーニング注文を作りません。

登録後の最初の取引日の引けに初回判断、その次の取引日の始値から約定可能です。観測開始前のリターンは「観測前」と表示します。

## 保存先と限界

`data/paper/forward_tests/` のJSONに判断・注文・約定・評価額を保存し、Actionsでコミットします。ルールとユニバースのハッシュが変わった場合は停止します。ルール変更は新しい口座として明示的に開始する必要があります。

日足での約定推定であり、板・実際の寄付き約定・注文拒否・全企業行動を完全には再現しません。取得元によるデータ訂正は過去の記録へ遡及適用しません。取得欠損で選別に偏りが出る可能性は残ります。GitHub Actionsの予定時刻は実行保証ではありません。

旧 `data/paper/diversified_*.json` および2023年から再構築する旧トレンドスクリーニング成績は、現行の公開フォワード成績から外しています。研究結果は「最新の検証状況」で独立して掲載します。
